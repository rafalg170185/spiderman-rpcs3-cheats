# Spider-Man RPCS3 Cheats

A community project dedicated to researching, documenting, and testing cheat patches for the PlayStation 3 versions of Spider-Man games in RPCS3.

## Supported Games

1. **The Amazing Spider-Man (2012)**
2. **The Amazing Spider-Man 2 (2014)**
3. **Spider-Man: Edge of Time (2011)**
4. **Spider-Man 3 (2007)**

## Project Goals

- Research existing cheat codes for each game.
- Identify the correct game version and PPU executable hash.
- Create patches using the format supported by RPCS3.
- Document reliable sources and compatibility information.
- Test patches before marking them as functional.

## Verification Policy

- No fabricated cheat codes or executable hashes.
- Every patch must match the appropriate game version.
- Sources and known limitations must be documented.
- A cheat will only be marked as tested after successful verification.

## Current Status

**Research and preparation in progress.**

No cheat patches have been confirmed as functional by this project yet.

## Contributions

Contributions are welcome. Please provide reliable sources, game version information, and testing results when submitting a patch.
